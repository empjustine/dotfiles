# Dotfiles — Known Documentation Issues

This file tracks known inconsistencies, gaps and drift in the documentation
set (README, BRD, SRD, TDD and the decision log). It is a working list, not a
requirements or design document: an entry is removed when the underlying
discrepancy is fixed, and the fix should be recorded in the relevant DR.

Entries reference sections by name rather than line numbers so they survive
edits. Status values: **open**, **partial** (partly fixed), **resolved**.
